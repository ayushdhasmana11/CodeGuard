# CodeGuard
C/C++ Source Code Plagiarism Detection System 



# Reader and Preprocessing
# Code Guard : Abhishek Bhandari
This project checks C++ code for plagiarism.  
The Reader module reads code from files.  
It provides code for the checking process.  
The Preprocessing module cleans code before comparison.  
It removes comments and unnecessary spaces.  
This makes code easier to compare.  
Both modules work together in CodeGuard.  
The cleaned code is sent for comparison.  
These modules help identify similar code in submissions.
